# 🍔 Сайт ресторана «Бургер Хаус»
Адаптивный веб-сайт ресторана быстрого питания с использованием Bootstrap 5 фреймворка, полным каталогом меню и интерактивными элементами для оформления заказов. Проект реализован на Bootstrap 5 и JavaScript с семантической версткой.


## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий


### Библиотеки и плагины
- **Bootstrap 5** — модальные окна, табы, карусель, адаптивная сетка
- **Fancybox** — галерея для видео-презентации


## 🎯 Ключевые функции

### UI/UX элементы
- Липкая навигация для шапки при скролле
- Плавная навигация по странице
- Главный слайдер (карусель) — автоматическая прокрутка промо-баннеров
- Табы для переключения товаров в меню
- Модальные окна — система оформления заказов и заявок
- Видео-презентация — встроенный видеоплеер с кастомным UI


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует чистую адаптивную верстку с использованием фреймворка Bootstrap 5 и уверенное владение современными библиотеками и подходами к веб-разработке.**
